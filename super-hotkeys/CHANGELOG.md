# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `super-hotkeys/v<version>`.

## 0.1.1 (2026-09-26)

- Holding a modifier now shows the key of Open plugins on the sidebar's Plugins
  item, in BB's navigation and in Dia Sidebar, and follows a key set in
  Settings → Keyboard.

## 0.1.0 (2026-09-25)

- First release, with Superhuman-like keyboard navigation: holding a modifier
  shows the keys still needed for the shortcuts of visible controls, slash
  opens Search threads, Command+P on a Mac and Ctrl+P elsewhere open the
  Plugins page, and while the prompt is empty, number keys set a new thread's
  project, model, machine, and branch.
