# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `todo/v<version>`.

## 0.1.0 (2026-10-27)

- First release: a Notes-style to-do list under the composer on the New thread
  screen, and in a **To-do** tab in the right panel. **Enter** adds a to-do,
  its handle sorts it, and checking moves it to **Done**. A snoozed to-do
  comes back at the top of the list, highlighted, when its time comes. A
  to-do's arrow button starts a thread from it. One list serves the whole BB
  server, so desktop and phone show the same to-dos.
