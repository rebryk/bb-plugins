Dictate to your agents with a speech model that runs on your own Mac.

## Voice input on the Neural Engine

The plugin transcribes BB's voice input with the Parakeet Ultra speech model
on the BB server's Neural Engine. The audio never leaves the Mac. A 10-second
take turns into text in about 0.3 seconds.

## 25 languages, no hesitations

The model finds the language on its own, among English, Russian, and 23 more
European languages, also mixed in one take. The plugin removes hesitations
such as "um" and "э-э".

## The built-in microphone, even with AirPods

Set Microphone to Built-in in Settings → Plugins → Voice Input. BB's voice
input then records with your Mac's, iPhone's, or iPad's own microphone, even
with AirPods or other headphones connected. Bluetooth headphones record worse,
so the built-in microphone transcribes better. The setting works with any
service that transcribes BB's voice input.

## Set up once

The BB server must run on a Mac with Apple silicon and macOS 15 or later, with
the Xcode Command Line Tools and ffmpeg. Pick Parakeet Ultra for voice input in
Settings → AI services. The plugin downloads the 350 MB model and gets ready on
its own.
