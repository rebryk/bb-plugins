# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `dia-sidebar/v<version>`.

## 0.1.1 (2026-09-25)

- The icons sit edge to edge, without gaps between them. Only the hovered and
  the current icon show a background, so the grid is more compact.

## 0.1.0 (2026-09-25)

- First release: a navigation option under Settings → Appearance → Navigation
  that turns the sidebar navigation into a compact, wrapping grid of icons,
  with other plugins' live indicators in each tile's lower-right corner. BB's
  menus, hidden items, and customization keep working.
