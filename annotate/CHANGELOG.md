# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `annotate/v<version>`.

## 0.1.0 (2026-10-13)

- First release: an **Annotate** button in the toolbar of the desktop app's
  Browser. Click an element, write a note, and the note goes to the composer
  as a numbered pill. The agent gets the note, the element's details, and a
  screenshot of the page around it. Pins mark the notes on the page until
  you send the message.
