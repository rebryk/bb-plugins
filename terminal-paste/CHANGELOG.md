# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `terminal-paste/v<version>`.

## 0.1.0 (2026-09-26)

- First release: on a phone or tablet, a Paste button in the header of the
  terminal's pane pastes the clipboard into the terminal. Where the page can't
  read the clipboard, as in the BB app on Android, Paste opens a text field
  instead.
